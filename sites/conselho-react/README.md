# Conselho NEJ Londrina · 2026

Página de memória do Conselho NEJ Londrina, desenvolvida com React e Vite.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run preview
```

O build é gerado em `dist/`. Na Vercel, basta importar este diretório como a raiz do projeto; o arquivo `vercel.json` já contém as configurações necessárias.
